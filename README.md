# rangoski

A fast-paced, addictive mosquito-swatting browser game built with **React 19** and **Vite**.

## 🎮 Gameplay
- **Objective**: Use your fly swatter to exterminate 10 mosquitoes.
- **Timer**: You have 10 seconds per mosquito before it escapes.
- **Chances Limit**: Maximum 5 swat attempts per mosquito — spam clicking will exhaust your chances and cause the mosquito to escape!
- **Speed Slider**: Customize mosquito movement speed across 5 difficulty levels (1x, 2.5x, 5x, 7.5x, 10x).
- **Themes**: Switch between sleek Dark and crisp Light mode.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/Barani1912/rangoski.git
cd rangoski

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **React 19**
- **Vite 6**
- **Lucide React** (vector icons)
- **Vanilla CSS** with modern design tokens & Google Fonts (`Plus Jakarta Sans` & `Outfit`)
